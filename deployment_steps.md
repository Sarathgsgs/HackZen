Steps for application deployment:

1. Make sure you have access to Source repository.
2. Fork the repository into your personal github account.
3. Create your own branch and make it as default.
4. Push your code into your branch.
5. Make sure you have .gitignore file to avoid unnecessary delays and unimportant files uploading.
6. Open your account in Vercel and render.
7. Login using your github account.
8. Connect your project repository for deployment.
9. In vercel and render upload Environment variables like api key, oauth credentials separately.
10. Check whether the latest commit is deployed.
11. for any changes to code just commit and push to your branch where the vercel and render will automatically pickup and deploy the latest commit.
12. If it does not automatically deploy , manually select the latest commit and deploy.
